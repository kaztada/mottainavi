# screens.md — 画面設計書

バージョン: v0.1 (2026-07-04)

---

## 1. 画面構成(3画面+α)

```
[S1] ホーム(検索)
  └→ [S2] 検索結果リスト
        └→ [S3] 品目詳細(捨て方+手放し方)
[S4] このサイトについて(出典・免責・作者)
```

モバイルファースト(375px基準)。PC表示は中央カラム最大640pxで同一レイアウト。

## 2. デザイントーン(#ちるエコ日和 準拠)

- **ゆるい・やわらかい・押しつけない**。行政ツールの無機質さと距離を置く
- 角丸大きめ(rounded-2xl)、余白たっぷり、影は薄く
- ベースは生成り/オフホワイト(#FAF9F6系)、アクセントはやわらかいグリーン
- 収集区分バッジは categories.json の色を淡くして使用(彩度を落とす)
- コピーの語り口: 「〜しましょう」ではなく「〜という手もあります」「〜してみるのもいいかも」
- 絵文字は控えめに使用可(🌱♻️程度)。過剰装飾はしない
- フォント: system-ui スタック(日本語は Hiragino Sans / Noto Sans JP フォールバック)

## 5. S3: 品目詳細 — このアプリの核

情報の順序が思想を表す: **「手放す」を先、「捨てる」を後**に置く(reuse_categoryがある品目のみ)。
ただし押しつけないよう、手放しセクションは折りたたみ気味の軽いカードで。

│ 🗑 大阪市での捨て方           │
│ ┌─────────────────────┐│
│ │[粗大ごみ]                ││
│ │処理手数料: 400円          ││
│ │粗大ごみ収集受付センターへ   ││

- 英語モード時: 品目名は name_en があれば英語、なければ日本語名+ローマ字かな。注意点(note)はMVPでは定型文の英語テンプレート(「Follow the category instructions. See the official page for details.」)+区分名英語で対応し、原文noteは折りたたみで日本語表示

## 6. S4: このサイトについて

- 目的(捨てる前にちょっと立ち止まる場所)
- 非公式ツールであること/最新・正確な情報は大阪市公式サイト参照
- 出典とライセンス表記: 大阪市「品目別収集区分一覧表」(CC-BY 4.0)を加工して作成
- データ取得日
- 作者: Kaz Tada(kaztada.eco へのリンク) — #ちるエコ日和 の文脈で軽く
- お問い合わせ/修正報告の導線(GitHub Issues or フォームリンク)

## 7. アクセシビリティ・その他

- 区分の識別を色だけに依存しない(バッジに必ずテキスト+アイコン)
- タップターゲット44px以上
- lang属性を言語切替に連動
- OGP設定(タイトル/説明/画像1枚)— SNSシェアで#ちるエコ日和発信に載せやすく
- 計測はプライバシー配慮の軽量ツール(Vercel Analytics)のみ。クッキーバナー不要の構成

## 9. S0: 自治体選択

```
┌─────────────────────────┐
│  🌱 もったいナビ         [EN]│
│  お住まいの市区町村を選んでください│
│                      [北海道]│
│                       [青森]│
│              … [福島] …     │
│      [島根][鳥取] [京都][滋賀]…│  ← デフォルメ日本地図
│   [山口][広島]…[大阪]…[東京]…  │    (都道府県のタイル)
│ [長崎][佐賀][福岡]            │
│ [沖縄]                      │
│  色のついた県に、対応している市が│
│  あります。下の一覧からも選べます。│
│  ┌───────────────────┐  │
│  │ 都道府県         ▼   │  │
│  └───────────────────┘  │
│  ┌───────────────────┐  │
│  │ 市区町村         ▼   │  │
│  └───────────────────┘  │
│                             │
│  ── 対応中の自治体 ──        │
│  [大阪市]                    │
│                             │
│  ⓘ 非公式ツールです。         │
└─────────────────────────┘
```

- **デフォルメ日本地図**(2026-10-07 Kaz の希望で追加): 47都道府県を同じ大きさのタイルにして、日本列島のおおよその並びに置く(13列×13行。北海道だけ2マス角)。実際の形の地図は、東京・大阪・香川などが小さすぎて指で押せないので使わない(Kaz「日本列島はデフォルメでいい」)
  - タイルを押すと、その都道府県が選ばれる(下の都道府県のセレクトと同じ状態を共有)。市区町村のセレクトが画面に入るようにスクロールする
  - 対応している市がある県は、色+太字+下線で示す(色だけに頼らない)。選択中は濃い緑の塗り
  - タイルの名前は都・府・県を外した短い形。読み上げ用の名前は正式名
  - 英語モードでは、タイル・都道府県のセレクト・県の地図の見出しを英語の名前にする(2026-10-08 Kaz「英語ページにした時に日本語のまま」)。タイルは小さいので、6文字以上の名前は読みの切れ目で2行に分ける(Kana / gawa。1行は5文字まで)。5文字でも、幅の広い字(m)で1行に収まらない Gunma は2行にする(Gun / ma。スマホ幅の画面で枠からはみ出したため)。Prefecture などは付けない
  - 同じことがセレクトでできるので、タイルはキーボードの移動先にしない
  - 並びは `src/lib/japan-tiles.ts`。データの取得はなく、最初の表示に含める(47個のボタンだけ)
- 都道府県 → 市区町村の2段セレクト。全国リスト(gzip 約40KB)はUIを開いたときだけ fetch
- 「対応中の自治体」チップで、データのある自治体へ1タップで行ける
- 市区町村セレクトでは未対応の自治体に「(未対応)」を添える(選ぶ前に分かるように)
- 未対応自治体のページを開いた場合も、その自治体を保存する(本人が選んだ自治体のため)
- 選択した自治体は localStorage(キー `mottainavi-municipality`)にスラッグを保存
- **再訪時**: `<head>` のインラインスクリプトが描画前に `/[municipality]` へ `location.replace`。
  言語切替と同じちらつき防止の手法。再訪ユーザーのタップ数は現行と変わらない
- **県の市区町村の地図**(2026-10-07 追加): 都道府県を選ぶ(タイルでもセレクトでも)と、その県の市区町村の地図がタイルの下に出る
  - 境界は「国土数値情報(行政区域データ)」(国土交通省、2021年版。国土数値情報の利用規約=出典の記載と加工した旨の記載が条件、商用も可)。県ごとのファイル(gzip で 3〜24KB)を、県を選んだときだけ読む。最初の表示には含めない
  - 小さい町は押しにくいので、押しただけでは進まない。押した市区町村の名前(未対応なら「(未対応)」つき)と「〇〇を開く」ボタンを出し、確かめてから進む
  - 対応済みの市区町村は、色+名前のラベルで示す(色だけに頼らない)。選択中は濃い緑+太い線
  - 離島が遠い県(東京都・鹿児島県・沖縄県)は本土側だけを地図にし、枠の外の市区町村は「地図の外の市区町村(離島など)」として名前のボタンで並べる(選べなくはならない)
  - 政令指定都市の区は作らない(Kaz: 区ごとに分別の違いが無ければ不要。対応済みの大阪市・横浜市・福岡市とも、区ごとの違いはデータに無い)。東京23区は、それぞれが1つの自治体
  - 地図の下と About に出典「地図の出典: 「国土数値情報(行政区域データ)」(国土交通省)を加工して作成。」を、出典のページと利用規約へのリンクつきで出す(`MapCredit`)
  - 飛び地: 囲む側の自治体には穴をあけて描く(穴をふさぐと、飛び地を押したときに囲む側が選ばれてしまう。船橋市・志布志市など)
  - 地図が読めないときは一言出して、セレクトで選んでもらう。図形はキーボードの移動先にしない(セレクトが主)

## 10. S0': 未対応自治体

status が `unsupported` の自治体ページ。**対応しているふりをしない**。

```
┌─────────────────────────┐
│ ← 自治体を選びなおす          │
│                             │
│  堺市                        │
│                             │
│  もったいナビは、堺市にはまだ  │
│  対応していません。           │
│  ごめんなさい、順番に増やして  │
│  いるところです。             │
│                             │
│  [ 堺市の公式サイトを見る ↗ ] │
│                             │
│  ── 対応中の自治体 ──        │
│  [大阪市]                    │
└─────────────────────────┘
```

- 検索ボックスは置かない(検索できると誤解させないため)
- `official_url` が判明していればリンク。無ければ「お住まいの自治体の公式サイトでご確認ください」
- `<meta name="robots" content="noindex">` を付ける(1,700件超の空ページをインデックスさせない)
- 全国1,741件ぶんをSSGする(実測: 全1,749ページのビルドが約15秒)

## 11. 自治体の切替(全画面共通ヘッダ)

```
┌─────────────────────────┐
│ 🌱 もったいナビ [📍大阪市|変更] [EN]│
└─────────────────────────┘
```

- 詳細・About では言語トグルの隣に自治体名。検索トップ(S1)ではタイトル行を崩さないよう説明文の下に置く
- ボタンは「📍 市名 | 変更」。市名だけだと押せる場所に見えにくい(2026-10-07 Kaz「ホーム画面に戻るメニューがない気がする」)ので、「変更」と言葉で添える
- 対応している自治体の全ページ(検索・品目の詳細・このサイトについて)のフッター(出典表記の下)にも「ほかの市区町村を選ぶ(地図へ)」のリンクを置く(行き先は同じ `/?change=1`)。未対応の自治体のページ(S0')は、ページの先頭に「自治体を選びなおす」があるので足さない
- 狭い画面(320px 幅など)で長い市名(英語名)がはみ出さないよう、ボタンの中の市名は末尾を省略する(「変更」は省略しない)
- 左上のタイトルは「その市の検索トップへ戻る」役目のままにする(自治体選択へのリンクにはしない)
- タップで `/?change=1` へ。このクエリがあるときは保存済み自治体への自動転送をしない(選びなおせなくなるのを防ぐ)
- 詳細ページで自治体を切り替えた場合は、新しい自治体のトップ(S1)へ移動する。
  品目IDは自治体間で対応しないため、同じ品目を追いかけない

## 12. S3(品目詳細)の変更点

- URL が `/[municipality]/item/[id]` になる
- クライアント描画のため、データ取得中は品目名の位置にスケルトンを表示する
- 存在しない品目IDは「この品目は見つかりませんでした」+ 検索へ戻る導線(ソフト404)
- 「🗑 大阪市での捨て方」の見出しは `{municipality}` で自治体名を差し込む
- 粗大ごみの申込セクションは、区分の `kind` が `bulky` のときに表示する。
  粗大ごみ制度が無い自治体、申込先が未登録の自治体では出さない
- 出典表記は自治体ごとの `source_attribution` / `source_attribution_en` を使う(CC-BY の義務は自治体ごとに異なる)

## 13. S4(このサイトについて)の変更点

- `/[municipality]/about` に移し、出典・ライセンス・データ取得日を自治体ごとに表示する
- 出典は「導入の1文(品目データは、次の出典のデータを加工して作成しています。)+ `source_attribution` をそのまま1ブロック」で表示する。
  `source_attribution` を文中に埋め込まない(自治体ごとに書式が違い、「加工して作成」「改変して利用しています。」などを含むものがあるため)
- 「対応自治体の一覧」と「まだ対応していない自治体について」の節を追加する
