# screens.md — 画面設計書

バージョン: v0.1 (2026-07-04)

---

## 1. 画面構成(3画面+α)

```
[S1] ホーム(検索)
  └→ [S2] 検索結果リスト
        └→ [S3] 品目詳細(捨て方+手放し方)
[S4] このサイトについて(出典・免責・作者)
```

モバイルファースト(375px基準)。PC表示は中央カラム最大640pxで同一レイアウト。

## 2. デザイントーン(#ちるエコ日和 準拠)

- **ゆるい・やわらかい・押しつけない**。行政ツールの無機質さと距離を置く
- 角丸大きめ(rounded-2xl)、余白たっぷり、影は薄く
- ベースは生成り/オフホワイト(#FAF9F6系)、アクセントはやわらかいグリーン
- 収集区分バッジは categories.json の色を淡くして使用(彩度を落とす)
- コピーの語り口: 「〜しましょう」ではなく「〜という手もあります」「〜してみるのもいいかも」
- 絵文字は控えめに使用可(🌱♻️程度)。過剰装飾はしない
- フォント: system-ui スタック(日本語は Hiragino Sans / Noto Sans JP フォールバック)

```
┌─────────────────────────┐

│                             │
│  ┌───────────────────┐  │
│  │ 🔍 品目名で検索          │  │ ← 即フォーカス
│  └───────────────────┘  │
│                             │
│  よく調べられるもの:          │
│  [ソファ] [スプレー缶]        │
│  [モバイルバッテリー] [傘]    │  ← チップは静的に8個程度
│                             │
│  ── 収集区分から見る ──      │
│  [普通ごみ] [資源ごみ]        │

```

- 検索は入力のたびにインクリメンタル実行(デバウンス150ms)。結果はS1内にそのまま展開(S2はS1と同一ページの状態変化として実装してよい)
- 0件時: 「見つかりませんでした。別の言い方で試すか、大阪市の一覧表もどうぞ →(公式リンク)」

## 5. S3: 品目詳細 — このアプリの核

情報の順序が思想を表す: **「手放す」を先、「捨てる」を後**に置く(reuse_categoryがある品目のみ)。
ただし押しつけないよう、手放しセクションは折りたたみ気味の軽いカードで。

```
┌─────────────────────────┐
│ ← ギター(木製)               │
│                             │
│ ♻️ 捨てる前に、こんな手も     │
│ ┌─────────────────────┐│
│ │🎸 楽器店の買取・下取り     ││
│ │  楽器は循環市場が成熟。    ││
│ │  [手間:中] [お金:入るかも] ││
│ └─────────────────────┘│
│ (カードは横スクロール/縦積み) │
│                             │
│ 🗑 大阪市での捨て方           │
│ ┌─────────────────────┐│
│ │[粗大ごみ]                ││
│ │処理手数料: 400円          ││
│ │粗大ごみ収集受付センターへ   ││
│ │申込みが必要です。          ││
│ │ [ネット申込 ↗] [☎ 電話]   ││
│ └─────────────────────┘│
│                             │
│ ⓘ 最新情報は大阪市公式サイト  │
│   でご確認ください [公式 ↗]  │
│ 出典: 大阪市「品目別収集区分   │
│ 一覧表」(CC-BY 4.0)          │
└─────────────────────────┘
```

- 複数区分の品目は捨て方カードを縦に並べ、条件(サイズ等)を見出しに
- 手数料があれば強調表示。粗大ごみはネット申込URL+電話番号(tel:リンク)
- 英語モード時: 品目名は name_en があれば英語、なければ日本語名+ローマ字かな。注意点(note)はMVPでは定型文の英語テンプレート(「Follow the category instructions. See the official page for details.」)+区分名英語で対応し、原文noteは折りたたみで日本語表示

## 6. S4: このサイトについて

- 目的(捨てる前にちょっと立ち止まる場所)
- 非公式ツールであること/最新・正確な情報は大阪市公式サイト参照
- 出典とライセンス表記: 大阪市「品目別収集区分一覧表」(CC-BY 4.0)を加工して作成
- データ取得日
- 作者: Kaz Tada(kaztada.eco へのリンク) — #ちるエコ日和 の文脈で軽く
- お問い合わせ/修正報告の導線(GitHub Issues or フォームリンク)

## 7. アクセシビリティ・その他

- 区分の識別を色だけに依存しない(バッジに必ずテキスト+アイコン)
- タップターゲット44px以上
- lang属性を言語切替に連動
- OGP設定(タイトル/説明/画像1枚)— SNSシェアで#ちるエコ日和発信に載せやすく
- 計測はプライバシー配慮の軽量ツール(Vercel Analytics)のみ。クッキーバナー不要の構成
